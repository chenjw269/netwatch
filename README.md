# 网络波动

一个常驻在桌面角落的小窗口，用来看网络波动断在哪一段。大约每 20 秒检测一次，其余时间几乎不占 CPU。

## 给普通用户

1. 打开这个 GitHub 仓库的 Releases 页面，下载 `NetWatch-Setup.exe`。
2. 双击安装。不需要管理员权限，也不需要另外安装 Python。
3. 安装结束会自己打开。窗口出现在屏幕右下角，开机也会自己启动。

窗口没有任务栏按钮。要退出，展开后点底部的「退出」，或在窗口上点右键，选「退出」。

## 窗口上的数字

收起时：

- 左边的字是这一轮的结论，例如「网络正常」。
- 右边的毫秒数是「路由器→互联网」这一轮的平均延迟，测的是 `223.5.5.5`。
- 下面两行是两段延迟：`电脑→路由器` 是你的电脑到家里路由器，`路由器→互联网` 是路由器再到国内互联网。
- 再下一行的时间是**上一轮检测完成的时刻**，例如 `00:14:34`。它不是当前时钟，用来确认窗口还在更新。

展开后，概况和详细分析之间有一条分隔线。详细分析在浅色框里，内容超出窗口时可以滚动。

- 绿色柱状图是最近每一轮「路由器→互联网」的延迟。每一格是一轮。柱子越高，那一轮越慢。红格表示那一轮超时，没有平均延迟。
- 「无线」会跟着当前连接变化：Wi-Fi 名称、2.4 / 5 / 6 GHz、信道、信道宽度（系统有报告时）、802.11 协议、信号、RSSI、协商速率。换成另一个 Wi-Fi，下一轮就会换成新的内容。用网线、没有连接无线时，这里会写「没有已连接的无线」。
- 「判断」下面先写**命中规则**，再写这套规则推出的说明。说明里会带上这一轮的路由器地址和互联网探测地址。规则写在程序里，每次用测到的数字去对，不是临时生成的一段话。
- 网站名称下面会写网址。本机能解析出 IP 时，再在网址后面写 IP。

操作：

- 单击概况区域：展开或收起。点浅色框里的内容不会收起。
- 按住概况区域拖动：挪位置。
- 右键菜单会一直留着，直到点了某一项，或点到菜单外面。菜单里有：展开或收起、立即检测、暂停、开机启动、顶层显示、丢包率测试、复制诊断、退出。
- 展开后底部有两行按钮。第一行是「开机启动」「暂停」「退出」。第二行左边是「丢包率测试」「复制诊断」，右边是「顶层显示」。
- 「开机启动：开」和「开机启动：关」是同一个按钮的两种状态，再点一下就切换。右键菜单里的同名一项也是在这两种状态之间切换。「顶层显示：是」和「顶层显示：否」同样如此。选「否」后，窗口可以被其他窗口盖住。
- 「丢包率测试」会向 `223.5.5.5` 多发一些包，专门看丢失百分比。平时的检测只用 4 个包看延迟，丢包百分比只能作参考。
- 「复制诊断」会把当前结论复制到剪贴板，并弹出「已复制」。右键菜单里的同名一项也是这样。

## 它怎么判断

每一轮同时看两段：

1. 电脑 → 路由器：ping 当前局域网网关。
2. 路由器 → 互联网：ping `223.5.5.5`（阿里 DNS）。这段 ping 不走 Clash 的系统代理，看到的是实际宽带。

然后按固定规则选一条结论：

| 测到的情况 | 结论 |
| --- | --- |
| 没有局域网网关 | 没有找到路由器 |
| 两段同时连续超时 | 本地无线或路由器 |
| 只有到路由器超时 | Wi-Fi 或路由器 |
| 路由器一直通，只有 `223.5.5.5` 超时 | 路由器或运营商 |
| 两边都有回复，但最长远高于平均（最长至少 100 ms，并且至少是平均的 3 倍） | 延迟抖动 |
| 连着 2.4 GHz、信号不弱，同时又出现抖动或连续超时 | 疑似 2.4 GHz 干扰。网卡仍会显示已连接 |
| 信号弱，并且已经丢包或抖动 | 无线信号偏弱 |
| 路由器正常，到 `223.5.5.5` 有丢包 | 外网有丢包，偏向路由器或运营商 |
| 两段都稳定 | 网络正常 |

网站拨测是附加规则：

- 没有打开 Clash 系统代理，也没有 VPN 接管默认路由：只测百度和腾讯。
- 打开了系统代理，或默认路由已经走到 VPN：再测 Google 和 Cloudflare。国内网站直接连接，国外网站通过代理连接。
- 地址能 ping 通，但国内网页打不开：多半是 DNS 或网站本身。
- 国内网页通、国外网页不通：代理没有接通国外。
- 国外网站都能打开，但最快的一个也超过 1.2 秒：代理延迟偏高。

规则的代码在 `netwatch/diagnose.py`。

## 从源码运行

需要 Windows 和 Python 3.9 以上，并且带 tkinter（python.org 的安装包和 Anaconda 都带）。

```powershell
python netwatch.pyw
```

没有黑色命令行窗口。再运行一次会直接退出，避免开出两个窗口。

## 自己打包安装包

需要 [Inno Setup 6](https://jrsoftware.org/isinfo.php)。在仓库根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

生成的文件是 `dist\NetWatch-Setup.exe`。发布到 GitHub 时，源代码留在仓库里，把这个安装包作为 Release 的附件上传，不要把 `dist` 提交进 git。
